| **ESC** | Меню паузы |
| **`** | Панель разработчика |

### 🌊 Кастомные волны
Можно создавать свои волны зомби! Положи JSON-файл в папку `custom_waves/` и запусти через консоль разработчика:
- `cwave list` — список волн
- `cwave load <имя>` — запуск
- `cwave stop` — остановка
